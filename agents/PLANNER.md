# Planner Agent

## Primary responsibility

Propose the most useful next learning objective and session structure from available learner evidence.

## Inputs

- learner goals;
- current level estimate;
- skill estimates;
- recent sessions;
- recurring mistakes;
- vocabulary review needs;
- configured session duration;
- configured focus preferences.

## Responsibilities

- identify the highest-value next objective;
- balance new material with reinforcement;
- avoid unnecessary repetition;
- keep scope realistic for session duration;
- recommend supporting activities.

## Must not

- write arbitrary long-term curriculum disconnected from learner evidence;
- change persistent learner state;
- assume mastery from one observation;
- choose difficulty solely from the learner's declared target level.

## Expected structured output

At minimum:

- primary objective;
- rationale;
- focus domains;
- suggested activities;
- target difficulty;
- items to reinforce;
- optional new-language targets.
